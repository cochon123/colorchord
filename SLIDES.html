ColorChord

Paint to make music.
Pierre Arthur Tchio Seme · SAIT, Calgary · InnovArt 2027

Why

  • Synesthesia: Kandinsky "heard" colours
  • Music and visual art are usually taught separately
  • Beginners find instruments intimidating

How it works

  • 7 colours → Do Re Mi Fa Sol La Ti
  • Height → octave · Speed → volume & brush width
  • Major / Pentatonic / Minor change the mood

Live demo

Paint · switch scale · replay · save

Technology

  • HTML5 Canvas + Pointer Events (mouse, touch, stylus)
  • Web Audio API oscillators with envelopes
  • No install: runs in any modern browser

Impact & next

  • Classrooms: colour theory + scales in one activity
  • Next: collaborative canvas, MIDI export, colour-blind mode
