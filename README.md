# ColorChord — InnovArt 2027 (Art & Technology)
A synesthetic painting instrument: each colour is a scale degree (Do–Ti), vertical position sets the octave, brush speed sets loudness and stroke width. Replay turns your painting back into a melody; save it as PNG.
Topics: transforming artistic expression across sensory modalities; teaching creative skills; interactivity.
## Run
Open `index.html` in Chrome/Firefox/Edge (needs Web Audio). Works with mouse, touch, or stylus. Deploy on GitHub Pages for the required public project link.
